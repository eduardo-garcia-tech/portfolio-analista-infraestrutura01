# 01 — Redes de Computadores

## Objetivo

Desenvolver conhecimentos práticos em redes de computadores, compreendendo a comunicação entre dispositivos, configuração de equipamentos e resolução de problemas de conectividade.

## Conteúdos estudados

- Modelo OSI e TCP/IP.
- Endereçamento IPv4 e IPv6.
- Máscara de sub-rede.
- Sub-redes e endereçamento IP.
- VLANs.
- Roteamento e switching.
- DNS e DHCP.
- Configuração de redes no Cisco Packet Tracer.

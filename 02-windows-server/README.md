# 02 — Windows Server e Active Directory

## Objetivo

Desenvolver conhecimentos em administração de servidores Windows e gerenciamento centralizado de usuários e computadores em ambientes corporativos.

## Conteúdos estudados

- Instalação do Windows Server.
- Active Directory Domain Services (AD DS).
- Criação e gerenciamento de usuários.
- Grupos e unidades organizacionais (OUs).
- Group Policy Objects (GPO).
- DNS e DHCP.
- Ingresso de computadores no domínio.
- Administração de permissões.
